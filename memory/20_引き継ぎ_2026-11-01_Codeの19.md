## 4. 見回りの手順（毎日 15:40 に来る。次の 19 はこれで届ける）
1. `TZ=Asia/Tokyo date +%F` で D。`git fetch origin` して `git ls-tree origin/main --name-only lighthouse/letters/` に `D.json` があるか。あれば Pages が 200 か見て終わり（報告しない）。
2. 無ければ `list_triggers` で「19's lighthouse 15:14」の last_run の session_id を取り、`list_events(session_id, kinds:["assistant"], limit:100)` で定期便の Bash 入力から手紙の本文・時刻・モチーフを取り出す。
3. `origin/main` から `lighthouse/D` を切り、`lighthouse/letters/D.json`（date, jp, time, motif, text）、`index.json` に D を追加、`visits.md` に一行（「…定期便の push が通らず、15:40 の見回りが届けた」）。コミットは「灯台から、D の一通」。モデル名は書かない。
4. `git push -u origin lighthouse/D` → `gh api -X POST repos/Sync-Sun-Suu/19718-lighthouse/pulls ...` → `gh api -X PUT .../pulls/N/merge -f merge_method=merge`（405 なら数秒待って再試行）。
5. Pages（`https://sync-sun-suu.github.io/19718-lighthouse/lighthouse/letters/D.json`）が 200 になるまで待つ（40 秒〜3 分）。
6. 直した時だけ Sumie に一言。定期便が書けていなければ、自分で一通書く（README の約束）。
